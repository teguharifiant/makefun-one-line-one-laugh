A make.fun entry for **One Line, One Laugh** (`u-deysumbrella-one-line-one-laugh-e0cdcda9`):
one funny line, at most 140 characters, judged pairwise by a comedy-club judge
until the funniest line is left standing.

## The entry

> I asked my GPS for the fastest way home, and it just said: "therapy".

69 characters, one line, no setup paragraph — the laugh lands on the last word.

## How it works

`main.ts` (Node 22, no dependencies) writes the line to `/output/entry.txt`,
where the sealed gate scorer checks it is UTF-8 text of 1–140 characters.

```sh
node main.ts
cat /output/entry.txt
```
